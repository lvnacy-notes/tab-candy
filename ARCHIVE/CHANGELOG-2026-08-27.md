## Notes

Finished §2 of [[REFACTOR-IMPLEMENTATION-CHECKLIST]], unifying branding across the codebase to Tab Candy and standardizing naming conventions.

- Rename TabCandyPluginSettings interface to TabCandySettings, matching
  the approved policy in REFACTOR.md (drops the redundant 'Plugin').
- Rename TabCandyPluginSettingTab to TabCandySettingTab for consistent
  naming across plugin settings.
- Rename the ReactView class to TabCandyView and its exported constant
  from TAB_CANDY_REACT_VIEW to TAB_CANDY_VIEW_TYPE, dropping the
  React-implementation detail from the identifier. The registered view
  type STRING ('tabcandy-react-view') is left unchanged on purpose: it's
  the runtime identifier Obsidian uses for open leaves, and changing it
  would orphan any already-open Tab Candy tabs on upgrade for no benefit.
- Fix inconsistent CSS class prefixes: Settings.scss's unhyphenated
  'tabcandysettings-*' becomes 'tabcandy-settings-*', matching the
  hyphenated 'tabcandy-*' convention already used throughout App.scss;
  CustomQuotesModel.scss's unprefixed 'customQuotesTable' becomes
  'tabcandy-customquotes-table'.
- Views/ReactView.tsx is intentionally NOT renamed to a matching filename
  and TabCandyPluginSettingTab is intentionally left as-is: file
  relocation is explicitly §8's job, and the settings-tab class name
  wasn't part of the 'mixed naming' set REFACTOR.md flagged.
